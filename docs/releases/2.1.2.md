## Required Env

```env
MONEYFLOW_ASR_PROVIDER=azure_speech
AZURE_SPEECH_KEY=<your-azure-speech-key>
AZURE_SPEECH_REGION=japaneast
AZURE_SPEECH_LANGUAGE=vi-VN
MONEYFLOW_ASR_MAX_AUDIO_SECONDS=15
MONEYFLOW_ASR_TIMEOUT_SECONDS=30
```

Region used: `japaneast`
Max audio duration: 15 seconds
Fallback: manual text entry stays available.

## P10C - Azure Voice Multi-Intent + Audio Persistence Hardening

Root cause of one-draft collapse:
- Weak Azure punctuation left multiple money clauses in one sentence.
- Split logic relied on amount spans and missed spoken Vietnamese amounts such as `năm mươi nghìn`.
- Bare short amounts such as `30` were not promoted to VND-thousand amounts in expense voice context.
- Noisy Azure `ký 600.000` could miss the intended income clause.

Root cause of missing audio badge:
- Voice Session confirmation passed `voiceRecordId=null` into transaction creation.
- Frontend converted audio to WAV for Azure but did not persist the original recorded audio through the existing voice audio upload path.

Files fixed:
- `QuickAmountParser`
- `QuickEntryParser`
- `VoiceSessionService`
- `VoiceSessionDetailResponse`
- `VoiceAudioService`
- `VoiceEntryCard.vue`
- `voice-session.ts`

Tests added:
- Azure weak punctuation keeps income, gas, and food drafts.
- Noisy `ký 600.000` transcript does not collapse to only gas.
- Spoken Vietnamese amounts split into three expense drafts.
- Audio voice session confirmation carries `voiceRecordId` for transaction audio metadata.

Audio path:
- Browser keeps the original compact recording for playback storage.
- Frontend sends WAV PCM to Azure for transcription.
- Backend creates a `VoiceRecord` for audio voice sessions.
- Frontend uploads original audio to `/api/voice-records/{voiceRecordId}/audio`.
- Confirmed transactions receive the same `voiceRecordId`, so transaction list/detail can show transcript plus audio when storage succeeds.

Known limitations:
- Live Azure UAT still required before marking 2.1.2 complete.
- If storage is disabled or upload fails, transaction still saves with transcript but audio remains unavailable.

## UAT Hardening & UI Audit (Patch P10B)

### Live UAT Verification
- **ASR Transcription**: Verified Azure Speech integration transcribes Vietnamese audio.
- **Draft Creation**: Single/Multi-draft parsed correctly by LLM interpreter.
- **Save/Confirm Blocker**: Fixed.
  - *Root Cause*: Mismatch in draft identifier naming. The backend response DTO uses `draftId`, but the frontend typescript type and mapper in `VoiceEntryCard.vue` mapped it from `d.id` (which was `undefined`). This resulted in API calls reaching `/drafts/undefined/confirm` and failing with a 500 status code.
  - *Resolution*: Updated `VoiceSessionDraft` interface in `src/types/voice-session.ts` and mapped the field using `d.draftId || d.id || ''` in `VoiceEntryCard.vue`. Confirm calls now correctly hit `/drafts/{draftId}/confirm`.

### UI Pattern Audit & Alignment
- **Ugly Navy Summary Panel**: Audited and replaced the harsh dark navy summary box (`bg-[#10213A] text-white`) in the multi-draft view with a soft premium cream/ink block.
- **Bulky Counters**: Refactored metrics blocks into clean, responsive inline pill badges (`bg-emerald-50`, `bg-amber-50`, `bg-slate-50`).
- **Heavy Gold CTA**: Replaced old gold palette (`#D4A72C` / `#FFF9E8`) with approved MoneyFlow gold (`#C89211`) and premium navy (`#10213A`).
- **ASR Warnings Scoping**: Scoped warnings in `VoiceReviewPanel.vue` by passing the `is-draft` attribute, ensuring global ASR warnings are not shown inside individual parsed drafts once a transcript is successfully obtained.
