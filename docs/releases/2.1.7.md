# MoneyFlow 2.1.7

Status: PLANNED / NOT IMPLEMENTED. P14A docs/audit/spec only.

Release target: Category/Jar Backend.

## Boundary

2.1.7 is a backend-first Category/Jar release. It should prepare a Jar Board backend without claiming frontend UI or changing transaction ledger behavior.

## Planned Scope

- Category/Jar backend audit and contract.
- Jar Board grouped read API.
- Category/Jar stats query layer.
- Category move and board reorder APIs.
- Safe archive/delete behavior.
- Backend release lock.

## Deferred Scope

- Frontend Jar Board UI.
- Category merge.
- Transaction-level jar snapshot.
- Automatic category creation from Voice/OCR hints.
- Broad dashboard/insight rewrite.
- Fake category seed changes.
- DB migrations unless later phases prove they are required.

## Current Backend Evidence

- Existing jar API: `/api/workspaces/{workspaceId}/jars`.
- Existing category API: `/api/workspaces/{workspaceId}/categories`.
- Existing category keyword API.
- Existing jar monthly summary/detail APIs.
- Existing dashboard category and jar breakdowns.
- Existing Financial Insight category/jar metrics.
- Existing transaction category FK; jar is derived through category.
- Existing hard-delete guards for used categories and jars.

## Non-Negotiables

- Jar is not wallet.
- Category belongs to jar or remains uncategorized.
- Category/Jar changes must not silently rewrite historical transactions.
- Used categories and jars must not be hard-deleted.
- Stats must use real posted, non-deleted transactions.
- Voice/OCR category hints must not silently create or guess final categories.
- Workspace isolation is required for every endpoint.

## Known Limitations

- Category Board API is not implemented yet.
- Board-level stats DTO is not implemented yet.
- Dedicated category move endpoint is not implemented yet.
- Combined board reorder endpoint is not implemented yet.
- Category merge is deferred.
- Transaction-level jar snapshot is deferred.
- Jar/color icon metadata is not fully supported by current schema.
