## P14E Runtime Additions

- Added category archive endpoint: `POST /api/workspaces/{workspaceId}/categories/{categoryId}/archive`.
- Added category restore endpoint: `POST /api/workspaces/{workspaceId}/categories/{categoryId}/restore`.
- Added jar archive endpoint: `POST /api/workspaces/{workspaceId}/jars/{jarId}/archive`.
- Added jar restore endpoint: `POST /api/workspaces/{workspaceId}/jars/{jarId}/restore`.
- Category archive is idempotent, hides the category from the default board, and preserves transaction links.
- Category restore blocks inactive parent jars with `CATEGORY_CANNOT_RESTORE_PARENT_JAR_ARCHIVED`.
- Category delete blocks transaction usage with `CATEGORY_DELETE_BLOCKED_HAS_TRANSACTIONS`.
- Jar archive blocks active categories with `JAR_ARCHIVE_BLOCKED_HAS_ACTIVE_CATEGORIES`.
- Jar restore uses existing allocation validation.
- Jar delete blocks any child category with `JAR_DELETE_BLOCKED_HAS_CATEGORIES`.
- Default board filtering hides archived categories and inactive jars; `includeArchived=true` returns them.
- Lifecycle mutations do not create, update, delete, or reassign transactions.

## UI Handoff

- Board: `GET /api/workspaces/{workspaceId}/category-board`.
- Stats: add `includeStats=true`; default period is current month, or pass `from` and `to`.
- Archive views: add `includeArchived=true`; normal board should omit it.
- Move: `POST /api/workspaces/{workspaceId}/categories/{categoryId}/move`.
- Reorder: `POST /api/workspaces/{workspaceId}/jars/reorder`, `POST /api/workspaces/{workspaceId}/categories/reorder`.
- Lifecycle: category/jar `POST /archive`, `POST /restore`, safe `DELETE`.
- Suggested mobile UI: jar board cards, uncategorized group, drag category between jars, quick archive, stats chips, plain friendly labels.

## Non-Negotiables

- Jar is not wallet.
- Category belongs to jar or remains uncategorized.
- Category/Jar changes must not silently rewrite historical transactions.
- Used categories and jars must not be hard-deleted.
- Stats must use real posted, non-deleted transactions.
- Voice/OCR category hints must not silently create or guess final categories.
- Workspace isolation is required for every endpoint.

## Known Limitations

- Category merge is deferred.
- Transaction-level jar snapshot is deferred.
- Moving category may affect historical jar grouping when reports derive jar from the current category relation.
- Jar/color icon metadata is not fully supported by current schema.
- Frontend Jar Board UI is not implemented yet.
- Drag-drop UI is not implemented yet.
- Bulk archive/delete is deferred.
- Multi-currency is unsupported.
- Voice/OCR category suggestions may need separate resolver tuning.
