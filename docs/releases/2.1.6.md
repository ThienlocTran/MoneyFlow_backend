Status: Backend Planning foundation in progress. P13A and P13B are complete.

## Boundary

2.1.6 is a backend-first planning release. It should build toward upcoming obligations, reserves, projection, and actually-spendable planning APIs. P13A does not implement runtime features.

## P13B Runtime Additions

- Added `planned_obligations`.
- Added planned obligation status, priority, recurrence type, and computed state.
- Added create/list/detail/update/cancel endpoints.
- Added validation for required name, positive amount, required due date, currency, priority, recurrence, and same-workspace wallet/category references.
- Added cancel behavior: `PLANNED -> CANCELLED`, repeated cancel returns cancelled state, `PAID` cancel blocked.
- Added recurrence storage only; generation is deferred.
- Added targeted integration tests proving workspace isolation and no transaction side effects.

Targeted tests:

`.\mvnw.cmd "-Dtest=*PlannedObligation*Tests,*PlanningObligation*Tests" test`

Result: 9 tests passed.

## Non-Negotiables

- Planned obligation does not affect wallet balance until paid as actual transaction.
- Reserve allocation does not create or destroy money.
- Expected income is not actually spendable.
- Receivable debt is not spendable until collected.
- Payable debt is not normal expense.
- Wallet snapshots remain reconciliation evidence.
- Drafts and fake data do not affect planning.
- Workspace isolation is required for every endpoint.

## Known Limitations

- Planning v1 contract is partially implemented through planned-obligation CRUD.
- No `/planning/overview` endpoint exists yet.
- Planned obligations are not yet integrated into projection or actually-spendable.
- Standalone payable debts are not included in the current planning formula.
- Current planning service subtracts recurring obligations but not overdue outflows separately.
- Reserve aggregates can overlap because cross-module deduplication is not inferred.
- Recurrence type is stored but recurrence generation is not implemented.
- No notification/scheduler exists.
- No frontend UI work is included in P13B.
