# MoneyFlow 2.1.5

Status: PLANNED / NOT IMPLEMENTED

Release target: backend Financial Insight foundation.

## Boundary

2.1.5 starts the Financial Insight backend module. P12A is documentation and audit only. It does not add runtime insight APIs, migrations, scheduled jobs, AI calls, or frontend UI.

## Product Direction

Financial Insight should answer:

- Tiền tháng này đến từ đâu?
- Tiền đang nằm ở ví nào?
- Tiền đã đi vào mục đích gì?
- Hũ nào đang tăng rủi ro vượt mức?
- Còn thật sự xài được bao nhiêu sau khi trừ tiền giữ lại và nghĩa vụ?
- Khoản nào cần người dùng xử lý tiếp?

Bad insight: `Bạn nên tiết kiệm hơn.`

Good insight: `Ăn uống đã dùng 1.250.000đ trong tháng này, cao hơn 38% so với trung bình 3 tháng. Nếu giữ tốc độ này, hũ Ăn uống có thể vượt khoảng 420.000đ.`

## Planned Backend APIs

Base path: `/api/workspaces/{workspaceId}/insights`

- `GET /overview?period=month`
- `GET /spending?from=YYYY-MM-DD&to=YYYY-MM-DD`
- `GET /actually-spendable?date=YYYY-MM-DD`
- `GET /anomalies?period=month`
- `GET /action-items`

These are proposed only. They are not implemented in P12A.

## Non-Negotiables

- Insights are read-only.
- Insights must be grounded in real backend data.
- No fake runtime insight data.
- No external AI calls in 2.1.5 backend foundation.
- No unconfirmed voice/receipt drafts in ledger metrics.
- No transfer or debt movement counted as normal income/expense.
- No-wallet income counts for income stats but not wallet balance.
- Actually spendable must reuse planning rules and show exclusions.
- Every insight must include evidence or data quality warnings.

## Known Gaps Before Implementation

- No public insight API exists yet.
- No dedicated insight query service exists yet.
- Income-by-source and no-wallet-income aggregate endpoints are missing.
- Baseline anomaly rules need a dedicated query over prior periods.
- Standalone payable debts are not currently subtracted from actually spendable.
- Category/jar missing groups need explicit insight handling.
- Frontend route/UI does not exist for insights.
