# MoneyFlow 2.1.5

Status: Backend Financial Insight foundation in progress. P12A and P12B are complete.

Release target: backend Financial Insight foundation.

## Boundary

2.1.5 starts the Financial Insight backend module. Current work is read-only backend foundation code and docs. It does not add frontend UI, scheduled jobs, migrations, or AI calls.

## Product Direction

Financial Insight should answer practical questions from real ledger data:

- Where did income come from?
- Where did spending go?
- Which categories and jars are driving risk?
- Which income has no wallet and therefore does not change wallet balance?
- Which records need user cleanup before analysis is complete?

Bad insight: generic advice without evidence.

Good insight: a deterministic statement backed by category amount, baseline, date range, exclusions, and action route.

- Added `FinancialMetricQueryService`.
- Added internal metric DTO records.
- Added aggregate metrics for income, expense, net cashflow, income source, no-wallet income, category spending, jar spending, uncategorized spending, and wallet-affecting summary.
- Added tests for formula exclusions, date boundaries, workspace isolation, and empty state.

## Planned Backend APIs

Base path: `/api/workspaces/{workspaceId}/insights`

- `GET /overview?period=month`
- `GET /spending?from=YYYY-MM-DD&to=YYYY-MM-DD`
- `GET /actually-spendable?date=YYYY-MM-DD`
- `GET /anomalies?period=month`
- `GET /action-items`

These APIs are not implemented yet.

## Non-Negotiables

- Insights are read-only.
- Insights must be grounded in real backend data.
- No fake runtime insight data.
- No external AI calls in 2.1.5 backend foundation.
- No unconfirmed voice/receipt drafts in ledger metrics.
- No transfer or debt movement counted as normal income/expense.
- No-wallet income counts for income stats but not wallet balance.
- Actually spendable must reuse planning rules and show exclusions.
- Every later insight card must include evidence or a data quality warning.

## Known Gaps

- No public insight API exists yet.
- No user-facing insight dashboard exists yet.
- No insight cards/text generation exists yet.
- No anomaly detection exists yet.
- Actually spendable insight wrapper is planned for P12D.
